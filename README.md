# 老K学英语

网站（原地址）：https://laodix579-beep.github.io/codex-test/

完整部署包：[下载 ZIP](downloads/frog-study-offline.zip)。解压后按 DEPLOY_WINDOWS.md 上传全部文件和目录；电脑端首页右上角用户菜单中的“保存完整网页”可导出包含插画、现有录音与个人进度的单文件备份，其他页面保留原有导出入口。

本次在原项目内更新电脑端 MVP 界面，继续使用原网站与 `downloads/frog-study-offline.zip` 下载地址。电脑端使用紫白浅色和书本标识，首页采用双人教室横幅、续学详情、今日学习打卡和八大分类卡片布局；分类学习展示 8 大主题，点击后进入 4 个二级分类，再开始版本 A 的图文练习。未收录的分类显示空状态，不补造词条或录音。手机原有界面和操作保留。

静态英语学习网页，提供单词仓库词条与例句录音。手机中译英练习采用全屏图片、英文填空和底部操作栏；手机软键盘输入、删除及输入法组合输入均支持敲击音。右上角“…”可切换音效、音量和语速。

手机和电脑的中译英练习均支持空格快捷操作：空白时跳格，填写后确认当前词并进入下一空；整句答完后再按空格进入下一题。

练习内容仍仅使用已有单词仓库。电脑端提供八大类导航；手机默认显示“基础入门”的 4 个有词条的二级分类。“基础入门”已收录 136 个词条：问候与礼貌用语 22 个、数字与数量 62 个、颜色 19 个、形状与大小 33 个；手机仅展示有词条的分类；电脑端空分类保留二级入口和添加词条功能。原始词库位于 `data/basic-vocabulary.json`，网页内嵌相同内容，可保存为完整单文件。

电脑端点击主题进入二级分类页面；手机点击主题保留原有分类弹窗。选择子分类进入对应词汇的中译英整组练习（问候与礼貌用语为 22 词）。练习默认显示图片，可在本轮关闭；新一轮默认再次开启。关闭练习回到原分类入口；电脑端首页可继续上次练习的位置。

“管理词条”保留按分类展示的单词卡片，用于添加、查看和单词试听；列表位于 `#words/manage/主题/分类`，全部词条位于 `#words/all`。每组的“整组练习”会按顺序练习该组全部词条，例如问候与礼貌用语共 22 个；顶部“开始背词”仍按每日目标抽取练习。旧浏览器中缺失或错误的内置词条分类会自动修正，保留学习进度。

点击单词的“开始练习”或分类中的“开始背词”，默认进入中译英填空游戏：答题前显示完整中文例句，英文例句只空出当前词条，其余文字直接给出；逐字母输入，短语按词分格。显示答案卡片会去掉英文末尾标点和符号，保留内部撇号与逗号；词条、例句和 MP3 映射原文保持不变。填写答案时，开题和重听均先朗读一遍完整英文例句，再朗读两遍目标单词（例如 The apple is red. → red → red）。词义显示在中文例句与英文填空之间，不再显示操作说明行。进入答对或标记完成后的词卡时，自动朗读一次当前单词或短语，点击词卡可重听。例句使用复数时按句中词形填写。没有可匹配的双语例句时继续使用原单词拼写题。答对后的词卡、释义与完整双语例句展示保持原样。输入和删除均有敲击音，空格确认当前词；答对后再次按空格进入下一题。可调整音效、查看答案、试听 GA 美式发音及例句，错题、重练和复习均记入单词学习记录。

仅早期词库版本升级沿用原有一次性迁移机制，替换当时旧单词仓库，课程、课程进度、手账及其他资料保留。本次 MVP 界面更新不触发词库迁移，也不重置现有词条或学习状态。替换前的原始资料在同一浏览器本地存储的 `:before-basic-us-v1` 键下保留一次恢复副本；该副本不会上传。

书面音标采用 DJ 英式符号；播放直接使用本包的 610 个 MP3。609 段来自提供包中的原项目录音，apple 是已提供的本地 eSpeak 测试录音，音色可能不同。本次不调用 TTS、不生成或重新处理录音、不要求 API Key。没有匹配 MP3 的新增内容会显示“暂无对应录音”。来源见 [AUDIO_CREDITS.md](AUDIO_CREDITS.md)。

顶部搜索仅检索当前单词仓库中的英文、中文释义和例句，支持大小写不敏感的部分匹配、Enter、清空和无结果提示。结果分别提供“朗读单词”“朗读例句”。独立试听词不再加入搜索结果；用户原先已存入仓库的词条仍保留。

完整 GitHub Pages 部署步骤和上传清单见 [Windows 上传说明](DEPLOY_WINDOWS.md)。本包保留原有配置及学习记录的存储键。GitHub Pages、手机离线缓存和单文件个人备份均使用这些已提供的 MP3。

网站朗读会先下载完整 MP3 并核对来源 SHA-256，再从内存播放，避免边下载边播放造成断续；同题重听复用缓冲，同时预加载本题后续录音和下一题。缓冲有数量及大小上限，不会将全部录音重复装入内存。加载期间显示提示；切题、退出或切换录音不会让旧的异步下载突然开始播放。

保留正常 1× 原速、慢速及稍快设置，并在支持的浏览器保持音高；练习内调整语速立即生效。原速 1× 保留原录音音色。朗读期间降低键盘及答题音效，停止后恢复原音效设置；播放器的音量/静音选择在连续播放中保持。原示范和自己的录音回放不会同时播放。音频本身未转码、降噪或重新生成，无法增加原录音没有的细节。

离线更新只复用来源哈希正确的完整录音；下载不完整或缓存损坏时联网重新获取。原有 610 个 MP3 原字节、存储键和学习记录保留。新增验证脚本 `tests/audio_quality.py` 检查全部原录音及电脑/手机播放，`tests/audio_cache_integrity.py` 检查旧缓存复用、损坏修复及离线 Range。

首屏在主程序加载前就确定桌面/手机布局，初始化期间使用独立加载页，完成后直接显示当前界面，避免旧深色桌面 MVP 闪现。慢速下载和启动失败也会显示明确状态，不会一直停在遮罩。联网导航会检查服务器版本；离线仍使用已保存的当前版本，不清空学习记录。

兼容缺少 `structuredClone`、`Object.hasOwn` 和 `Array.at` 的手机内置浏览器。启动期间会显示加载提示；初始化失败会显示重新加载入口，无需清空学习记录。

学习进度保存在当前浏览器。手机更新后需联网刷新，并等待“已保存离线内容”再断网；该提示会核对当前控制页面的缓存版本，避免离线退回旧版。首次联网完成缓存后可以离线使用；跨设备通过“设置与备份”导出、导入学习记录。

电脑端“显示答案”打开居中、带遮罩的独立弹窗，可以遮住题目。弹窗只有一个显式“关闭”按钮，另有播放已有 MP3 的发音按钮。点击任何非发音位置，或按任意键，都会关闭弹窗；发音按钮只播放，不关闭。用于关闭的按键和组合键会被完整拦截，不会同时输入、提交或切题。关闭后保留原题输入、选区及光标。查看答案不记录答对；提交正确后才显示绿色反馈、更新掌握记录，之后可进入下一题。

练习中的中文例句用界面紫色标出当前词条对应的部分，词义及参考答案中的作答词使用同色；短语、复数词形和不连续的中文对应片段也按原题处理。例如 half 对应“半个”，how are you 对应“你……好吗”，不会把中间“今天”一起标色。133 个例句有经核对的对应片段；any、zero、size 这 3 个例句显示各自的“本句用法”，不强行认定某个中文字是该词的独立翻译。

对应资料位于 `data/meaning-catalog.json`，随页面内嵌、离线缓存、个人单文件和部署 ZIP 提供。`python3 tools/build_meaning_assets.py` 核对原词库并重新内嵌资料；原词条、释义、例句及录音不改写。导入相同双语例句的副本可复用标色；修改了词义或双语例句时不会套用旧对应关系，而会保留完整原句与词条释义并提示结合整句理解。新增校验见 `tests/meaning_targets.py`。

首页“上次学习到哪里”卡片展示真实分组、下次词条位置和已掌握进度。“查看详情”列出本组词条及状态，可选择某个词开始练习；“继续学习”和“hello 的用法”等入口沿用同一练习组。本轮位置与历史掌握状态分别保存：复习到第 4 题时，返回首页、刷新或重新打开仍从第 4 题继续；本题提交正确或标记熟悉度后，续学指向下一题。查看答案不会推进位置。整组已掌握但仍在复习时显示“继续复习”，本轮结束后可重新练习，始终保留已有掌握记录。旧版保存的位置、JSON 备份和个人单文件导出兼容。

“今日学习打卡”同时检查每日学习时长和不同词条练习数，目标读取原有学习计划；两项都达标才能完成打卡，未达标时点击按钮会打开规则和剩余进度。重复练习同一词条不重复计数。已记录的打卡在调整目标后仍保留，历史打卡不重算。规则窗口可跳到每日目标设置和学习记录。

首页下方八大分类显示仓库实际词数，点击进入对应二级分类；“查看全部”进入分类学习。右上角用户菜单提供个人资料填写、每日目标、学习记录、完整网页保存、备份和导入。个人资料包含必填的姓名与年级，保存后首页右上角立即显示姓名；刷新、同浏览器其他页面、备份/导入及个人单文件均保留资料。旧备份没有年级时仍可恢复，原称呼和学习记录保留。侧栏“设置”保留原朗读与备份功能，并提供资料编辑入口。搜索仍检索仓库英文、中文和例句。原统计、日历及更多功能继续保留。

首页插画位于 `assets/home-hero.png`，随网站、离线缓存和完整部署 ZIP 提供；保存个人单文件时会内嵌该图及原 MP3，无需另带资源。

现有 136 个词条的例句都有对应卡通场景，人物优先沿用首页男孩、女孩的造型，根据语义选择单人或必要的老师、家人等人物；颜色、形状及大小突出句中的物品和特征。问候、数字、颜色、形状四组在切题、提交反馈及答案弹窗中使用同题配图；原图片开关保留。数字题在场景教学板上显示可核对的数量、序数、分数、时钟或日历图示，不显示英文拼写答案。

136 个场景使用 `assets/scenes/` 的 17 张原始合集图及 1 张独立修正图，由页面按词条和例句选择对应区域；PNG 未重新编码或裁切，数量图示由页面叠加以保证个数正确。第 9/22 题“明天见”改用 `see-you-tomorrow.png`：男孩正面斜侧身、右手自然挥手，左臂由身体遮挡，其余题图保持原样。映射见 `data/scene-catalog.json`，原生成文件哈希见 `reports/scene-source-sha256.json`。全部图片随离线缓存、完整部署 ZIP 及个人单文件保存。新增或改写的自定义内容没有匹配场景时如实提示，不错误套用其他题的图，也不调用生成 API。保持原数据存储键、词库版本、学习记录和全部 MP3 不变。

电脑端“学习进度”提供今日时长、今日练习单词、连续打卡和累计已学单词四张统计卡片；累计词数为历史记录及熟悉度中的不同词条去重，保留已删除词条的历史计数。每日目标及剩余进度沿用学习计划，“调整目标”可直接修改，“继续完成目标”从已保存的位置打开原练习；两项目标达标后可在此完成打卡。

近 7 天趋势可切换学习时长、练习单词和打卡情况；点击柱形或记录日期打开当天详情。分类进度为当前仓库已掌握数 / 词数，八大类均可进入对应二级分类，未收录分类如实显示 0 / 0。最近记录按日期显示，点击“查看更多”分页查看全部学习日并导出 UTF-8 CSV。原学习日排行和挑战历史保留在页面下方“历史排行与挑战记录”中。手机原记录页保留；新进度页也可在离线缓存和个人单文件中使用。

电脑端填空期间，点击图片、题目文字、空白区域或完成朗读操作后，仍保留当前输入框的真实焦点、已输入内容和光标选区，可直接继续输入。设置中的输入框、复选框、音量、语速、Tab 键导航、答案弹窗、暂停和切题保留各自的操作行为。

电脑端右侧展示本轮完成数量、正确率、剩余题数和用时；图片、键盘音、音量、语速及原有练习模式在侧栏中保留。学习计划、手账、收藏、挑战、AI 等原有入口可在“更多功能”中打开；原有统计、日历和打卡在首页展开查看。历史记录、设置、存储键及备份沿用，新增可选续学位置字段。
