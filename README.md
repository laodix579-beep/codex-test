# 小蛙自习室

手机访问：https://laodix579-beep.github.io/codex-test/

完整部署包：[下载 ZIP](downloads/frog-study-offline.zip)。解压后按 DEPLOY_WINDOWS.md 上传全部文件和目录；网页右上角“保存完整网页”可另行导出含现有录音与个人进度的单文件备份。

静态英语学习网页，提供单词仓库词条与例句录音。手机中译英练习采用全屏图片、英文填空和底部操作栏；手机软键盘输入、删除及输入法组合输入均支持敲击音。右上角“…”可切换音效、音量和语速。

手机和电脑的中译英练习均支持空格快捷操作：空白时跳格，填写后确认当前词并进入下一空；整句答完后再按空格进入下一题。

学习入口仅保留单词仓库中已有词条的分类，默认显示“基础入门”的 4 个二级分类。“基础入门”已收录 136 个词条：问候与礼貌用语 22 个、数字与数量 62 个、颜色 19 个、形状与大小 33 个；空分类不再展示。原始词库位于 `data/basic-vocabulary.json`，网页内嵌相同内容，可保存为完整单文件。

点击主题会弹出该主题的 4 个子分类；选择子分类进入对应词汇的中译英整组练习。首页的二级分类也可直接进入该组练习（问候与礼貌用语为 22 词）。练习默认显示图片，可在本轮关闭；新一轮默认再次开启。关闭练习回到分类入口。

“管理词条”保留按分类展示的单词卡片，用于添加、查看和单词试听；列表位于 `#words/manage/主题/分类`，全部词条位于 `#words/all`。每组的“整组练习”会按顺序练习该组全部词条，例如问候与礼貌用语共 22 个；顶部“开始背词”仍按每日目标抽取练习。旧浏览器中缺失或错误的内置词条分类会自动修正，保留学习进度。

点击单词的“开始练习”或分类中的“开始背词”，默认进入中译英填空游戏：答题前显示完整中文例句，英文例句只空出当前词条，其余文字直接给出；逐字母输入，短语按词分格。显示答案卡片会去掉英文末尾标点和符号，保留内部撇号与逗号；词条、例句和 MP3 映射原文保持不变。填写答案时，开题和重听均先朗读一遍完整英文例句，再朗读两遍目标单词（例如 The apple is red. → red → red）。词义显示在中文例句与英文填空之间，不再显示操作说明行。进入答对或标记完成后的词卡时，自动朗读一次当前单词或短语，点击词卡可重听。例句使用复数时按句中词形填写。没有可匹配的双语例句时继续使用原单词拼写题。答对后的词卡、释义与完整双语例句展示保持原样。输入和删除均有敲击音，空格确认当前词；答对后再次按空格进入下一题。可调整音效、查看答案、试听 GA 美式发音及例句，错题、重练和复习均记入单词学习记录。

旧版浏览器首次打开新版时，替换原有单词仓库并重置单词学习状态，课程、课程进度、手账及其他资料保留。替换前的原始资料在同一浏览器本地存储的 `:before-basic-us-v1` 键下保留一次恢复副本；该副本不会上传。

书面音标采用 DJ 英式符号；播放直接使用本包的 610 个 MP3。609 段来自提供包中的原项目录音，apple 是已提供的本地 eSpeak 测试录音，音色可能不同。本次不调用 TTS、不生成或重新处理录音、不要求 API Key。没有匹配 MP3 的新增内容会显示“暂无对应录音”。来源见 [AUDIO_CREDITS.md](AUDIO_CREDITS.md)。

顶部搜索仅检索当前单词仓库中的英文、中文释义和例句，支持大小写不敏感的部分匹配、Enter、清空和无结果提示。结果分别提供“朗读单词”“朗读例句”。独立试听词不再加入搜索结果；用户原先已存入仓库的词条仍保留。

完整 GitHub Pages 部署步骤和上传清单见 [Windows 上传说明](DEPLOY_WINDOWS.md)。本包保留原有配置及学习记录的存储键。GitHub Pages、手机离线缓存和单文件个人备份均使用这些已提供的 MP3。

兼容缺少 `structuredClone`、`Object.hasOwn` 和 `Array.at` 的手机内置浏览器。启动期间会显示加载提示；初始化失败会显示重新加载入口，无需清空学习记录。

学习进度保存在当前浏览器。手机更新后需联网刷新，并等待“已保存离线内容”再断网；该提示会核对当前控制页面的缓存版本，避免离线退回旧版。首次联网完成缓存后可以离线使用；跨设备通过“设置与备份”导出、导入学习记录。

在仓库目录启动开发服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

服务器运行后执行当前词库版本回归检查（需要 Python Playwright 和 `/usr/bin/chromium`）：

```sh
python3 tests/answer_punctuation.py
python3 tests/warehouse_scope.py
python3 tests/word_catalog.py
python3 tests/word_entry.py
python3 tests/word_spelling.py
python3 tests/word_cloze.py
python3 tests/navigation_audio.py
python3 tests/mobile_startup.py
python3 tests/sentence_word_audio.py
python3 tests/speech_reference.py
```

检查覆盖手机输入事件的单次音效、音效静音、触屏答题、键盘弹出布局、离线重开及桌面快捷键。

词库检查覆盖分类入口、136 个词条、旧数据迁移、分类练习、添加和备份、GA 录音映射、音频解码、离线播放及不同屏幕尺寸。


本版本已移除课程广场、教材同步、音标课程入口，旧链接返回单词仓库。首页学习入口、搜索、计划和收藏也仅展示仓库词条。历史课程、句子进度和收藏继续保存在原存储中，并随完整备份导出；导出个人网页不再自动补入旧教材。

`tests/mobile_practice.py`、`tests/space_shortcuts.py` 中的旧教材流程、`tests/pep_pronunciation.py` 的独立音标页和 v15 的 `tests/recording_integration.py` 独立试听词场景属于历史范围，当前未将这些旧流程列作通过检查。当前测试报告见 `reports/test-report.md`。
