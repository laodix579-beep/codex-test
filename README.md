# 小蛙自习室

手机访问：https://laodix579-beep.github.io/codex-test/

静态英语学习网页，内置课程与题目音频。手机中译英练习采用全屏图片、英文填空和底部操作栏；手机软键盘输入、删除及输入法组合输入均支持敲击音。右上角“…”可切换音效、音量和语速。

手机和电脑的中译英练习均支持空格快捷操作：空白时跳格，填写后确认当前词并进入下一空；整句答完后再按空格进入下一题。

学习进度保存在当前浏览器。首次联网完成缓存后可以离线使用；跨设备通过“设置与备份”导出、导入学习记录。

在仓库目录启动开发服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

服务器运行后执行手机练习回归检查（需要 Python Playwright 和 `/usr/bin/chromium`）：

```sh
python3 tests/mobile_practice.py
python3 tests/space_shortcuts.py
```

检查覆盖手机输入事件的单次音效、音效静音、触屏答题、键盘弹出布局、离线重开及桌面快捷键。
