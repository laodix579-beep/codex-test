# 小蛙自习室

手机访问：https://laodix579-beep.github.io/codex-test/

本次修改的离线版：[下载 ZIP](downloads/frog-study-offline.zip)。解压后打开 HTML；后续可通过网页右上角“保存完整网页”导出含当前学习进度的最新版。

静态英语学习网页，内置课程与题目音频。手机中译英练习采用全屏图片、英文填空和底部操作栏；手机软键盘输入、删除及输入法组合输入均支持敲击音。右上角“…”可切换音效、音量和语速。

手机和电脑的中译英练习均支持空格快捷操作：空白时跳格，填写后确认当前词并进入下一空；整句答完后再按空格进入下一题。

单词仓库以 8 大主题、32 个二级分类为入口。“基础入门”已收录 136 个词条：问候与礼貌用语 22 个、数字与数量 62 个、颜色 19 个、形状与大小 33 个；其他分类保留入口，后续添加。原始词库位于 `data/basic-vocabulary.json`，网页内嵌相同内容，可保存为完整单文件。

点击主题会弹出该主题的 4 个子分类；选择子分类进入对应词汇的中译英整组练习。首页的二级分类也可直接进入该组练习（问候与礼貌用语为 22 词）。练习默认显示图片，可在本轮关闭；新一轮默认再次开启。关闭练习回到分类入口。

“管理词条”保留按分类展示的单词卡片，用于添加、查看和单词试听；列表位于 `#words/manage/主题/分类`，全部词条位于 `#words/all`。每组的“整组练习”会按顺序练习该组全部词条，例如问候与礼貌用语共 22 个；顶部“开始背词”仍按每日目标抽取练习。旧浏览器中缺失或错误的内置词条分类会自动修正，保留学习进度。

点击单词的“开始练习”或分类中的“开始背词”，默认进入与教材同步相同的中译英游戏：答题前显示完整中文例句，英文例句只空出当前词条，其余文字直接给出；逐字母输入，短语按词分格。填写答案时，开题和重听均先朗读一遍完整英文例句，再朗读两遍目标单词（例如 The apple is red. → red → red）。词义显示在中文例句与英文填空之间，不再显示操作说明行。进入答对或标记完成后的词卡时，自动朗读一次当前单词或短语，点击词卡可重听。例句使用复数时按句中词形填写。没有可匹配的双语例句时继续使用原单词拼写题。答对后的词卡、释义与完整双语例句展示保持原样。输入和删除均有敲击音，空格确认当前词；答对后再次按空格进入下一题。可调整音效、查看答案、试听 GA 美式发音及例句，错题、重练和复习均记入单词学习记录。

旧版浏览器首次打开新版时，替换原有单词仓库并重置单词学习状态，课程、课程进度、手账及其他资料保留。替换前的原始资料在同一浏览器本地存储的 `:before-basic-us-v1` 键下保留一次恢复副本；该副本不会上传。

书面音标仅使用 DJ 英式符号；词条、例句及原有课件的朗读均采用 GA 美式发音，离线可播放。单独的单词以清晰模式生成，稍放慢模型语速，保留音色、长短音与完整词尾；句子按完整语句生成，以 0.9 模型语速保留上下文重音、弱读和自然连读；保留完整音频尾部，避免裁掉句尾辅音。音标课程中的“PEP 重点发音试听”可核对 /z/、th、/v/、重点英美差异词、thirteen/thirty 和 close 的两种读音。close 的单词朗读按中文词义选择录音，词库中已有学习记录保持不变。内置录音通过英语发音词典和全精度模型生成；单词卡中的单词、例句按标准速度试听，练习时仍可自行调节语速。后来手动添加的新词优先使用浏览器的 `en-US` 语音包。音频来源和可选重新生成方式见 [AUDIO_CREDITS.md](AUDIO_CREDITS.md)。

各个弹窗均提供带文字的“返回”按钮，普通页面也可返回上一级；退出练习会停止播放并保留已保存的学习进度。

兼容缺少 `structuredClone`、`Object.hasOwn` 和 `Array.at` 的手机内置浏览器。启动期间会显示加载提示；初始化失败会显示重新加载入口，无需清空学习记录。

学习进度保存在当前浏览器。手机更新后需联网刷新，并等待“已保存离线内容”再断网；该提示会核对当前控制页面的缓存版本，避免离线退回旧版。首次联网完成缓存后可以离线使用；跨设备通过“设置与备份”导出、导入学习记录。

在仓库目录启动开发服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

服务器运行后执行手机练习回归检查（需要 Python Playwright 和 `/usr/bin/chromium`）：

```sh
python3 tests/mobile_practice.py

python3 tests/word_catalog.py
python3 tests/word_spelling.py

```
