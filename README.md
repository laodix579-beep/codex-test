# 小蛙自习室

手机访问：https://laodix579-beep.github.io/codex-test/

静态英语学习网页，内置课程与题目音频。手机中译英练习采用全屏图片、英文填空和底部操作栏；手机软键盘输入、删除及输入法组合输入均支持敲击音。右上角“…”可切换音效、音量和语速。

手机和电脑的中译英练习均支持空格快捷操作：空白时跳格，填写后确认当前词并进入下一空；整句答完后再按空格进入下一题。

单词仓库以 8 大主题、32 个二级分类为入口。“基础入门”已收录 136 个词条：问候与礼貌用语 22 个、数字与数量 62 个、颜色 19 个、形状与大小 33 个；其他分类保留入口，后续添加。原始词库位于 `data/basic-vocabulary.json`，网页内嵌相同内容，可保存为完整单文件。

“本类全部”和“全部词条”均按二级分类集中展示，不同分类的词条分别归组。每组的“整组练习”会按顺序练习该组全部词条，例如问候与礼貌用语共 22 个；顶部“开始背词”仍按每日目标抽取练习。旧浏览器中缺失或错误的内置词条分类会自动修正，保留学习进度。

点击单词的“开始练习”或分类中的“开始背词”，默认进入与教材同步相同的中译英游戏：看中文释义，逐字母输入英文，短语按词分格。输入和删除均有敲击音，空格确认当前词；答对后再次按空格进入下一题。可调整音效、查看答案、试听美式发音及例句，错题、重练和复习均记入单词学习记录。

旧版浏览器首次打开新版时，替换原有单词仓库并重置单词学习状态，课程、课程进度、手账及其他资料保留。替换前的原始资料在同一浏览器本地存储的 `:before-basic-us-v1` 键下保留一次恢复副本；该副本不会上传。

词条、例句及原有课件均内置美式英语音频，离线可播放。书面音标采用英式 DJ 体系，配音采用美式英语，部分元音和 r 音有所区别。内置录音通过英语发音词典和全精度模型生成；单词卡中的单词、例句按标准速度试听，练习时仍可自行调节语速。后来手动添加的新词优先使用浏览器的 `en-US` 语音包。音频来源和可选重新生成方式见 [AUDIO_CREDITS.md](AUDIO_CREDITS.md)。

学习进度保存在当前浏览器。首次联网完成缓存后可以离线使用；跨设备通过“设置与备份”导出、导入学习记录。

在仓库目录启动开发服务器：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

服务器运行后执行手机练习回归检查（需要 Python Playwright 和 `/usr/bin/chromium`）：

```sh
python3 tests/mobile_practice.py
python3 tests/space_shortcuts.py
python3 tests/word_catalog.py
python3 tests/word_spelling.py
python3 tests/speech_reference.py
```

检查覆盖手机输入事件的单次音效、音效静音、触屏答题、键盘弹出布局、离线重开及桌面快捷键。

词库检查覆盖分类入口、136 个词条、旧数据迁移、分类练习、添加和备份、美式语音筛选、音频解码、离线播放及不同屏幕尺寸。
