# 电脑端 MVP 界面与交互测试报告

日期：2026-10-25（北京时间）。基于 3145ecd 原项目继续修改；缓存版本 `frog-desktop-mvp-v18`。

## 本次更新

- 在原页面与学习引擎上新增电脑端呈现，未重建项目。首页参考版本 C，练习参考版本 A，紫白浅色及书本标识。
- 电脑端流程：首页续学 / 分类学习 → 八大类 → 二级分类 → 练习 → 查看答案 → 关闭回原题 → 提交正确反馈 → 下一题。
- 八大类为导航，练习数据仍是已有仓库的 136 个词条及用户自己的词条。当前基础入门四组分别为 22、62、19、33 个。空分类有明确空状态，不添加试听词或虚构内容。
- 答案弹窗居中、遮罩、可覆盖原题；仅一个显式“关闭”按钮。发音控件只播放已有录音并保持打开；点击其他任意位置或任意按键关闭。
- 关闭按键、组合键、按住重复事件完整拦截，不触发输入、判分、朗读或切题。关闭后原题输入、选区、焦点不变。
- 查看答案与答对判分分离；正确提交后显示绿色反馈、更新本轮统计和掌握状态，再进入下一题。
- 原有模式、声音设置、手账、计划、收藏、挑战、AI 入口及首页统计/打卡保留。新增可选续学位置字段，沿用原存储键和原词库版本。
- 手机保留既有界面与交互；本次没有设计新手机界面。

## 实际执行并通过的检查

1. `tests/desktop_mvp.py`：完整桌面流程，8 类/4 子类，空状态，答案弹窗中心位置、模态遮罩、唯一关闭按钮；内容/插图/遮罩点击及 a、空格、Enter、方向键、Shift+方向键、Ctrl+A、Esc、Tab、F5 关闭，不触发题目操作；发音按钮保持弹窗并实际播放对应 MP3；输入选区不变；查看不判分；错误/正确提交、统计、下一题、原模式、续学、历史/设置/备份保留。窗口跨过桌面断点后仍保留原题、22 词组和返回位置。布局覆盖 1024×768、1280×800、1366×768、1440×960、1920×1080。
2. `tests/answer_punctuation.py`：桌面弹窗及原手机答案提示移除末尾符号，保留内部撇号/逗号、DJ 音标、原始例句和录音映射；正确判分。

6. `tests/word_spelling.py`：逐字输入/删除单次音效、正误判分、复习、短语、缩写、答案关闭隔离、音效开关和手机输入法输入。
