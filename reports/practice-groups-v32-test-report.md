# 复合分类练习选择测试报告

日期：2026-10-26（北京时间）。基于原项目 `f8225f3`，缓存版本 `frog-practice-groups-v32`。

## 功能

电脑端点击复合二级分类后显示居中遮罩弹窗：上方整组练习，下方真实语义小类，各自显示“共：N 个词条”。问候与礼貌用语当前为整组 22 条、问候 14 条、礼貌用语 8 条。数字、形状与大小及时间与自然的四个二级分类也提供实际小类。颜色等单一类别直接进入原练习，不弹出额外选择。空分类保留原添加词条入口。

小类按稳定原词 ID 划分，同一二级分类内不重不漏，原顺序保留。数量由当前词库计算；空小类隐藏，自定义新增词不丢弃，列入“其他词条”。只有一个非空小类时直接进入练习。分组资料单独保存在 `data/practice-groups.json` 并内嵌网页，未改写原 356 条词汇、DJ 音标、MP3、配图或映射。

关闭、Esc 或点击遮罩返回原分类，不开始练习或判分。选定后沿用原练习、MP3 播放、场景、参考答案和提交判分；首页续学保存本次小类的词条 ID 与当前位置，仍使用原存储格式。原完整分类直达链接、词条管理整组按钮、搜索、手机原有分类操作及既有记录保持。选择窗口在导航及切换手机布局时关闭，避免误开全分类练习。
