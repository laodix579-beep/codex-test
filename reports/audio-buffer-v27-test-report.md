# 原录音完整缓冲与播放修复测试报告

日期：2026-10-25（北京时间）。基于 c62796a 原项目；缓存版本 `frog-audio-buffer-v27`。

## 检查结论与本次修改

- 全部 610 个 MP3 与用户提供文件的来源 SHA-256 一致。FFmpeg 内存解码及 Chromium 全量解码均成功，时长有效、非静音，未发现削波。FFmpeg 检测到的最大样本峰值为 0.803148；浏览器重采样后最大值约 0.809。没有调用 TTS、重新生成、转码、降噪或替换录音。
- 发布播放器前，逐个请求原网站的全部 610 个 MP3：均为 HTTP 200，字节哈希均与来源一致。此前线上抽检也返回正确的 MP3 MIME 和 Range 支持。原文件本身完整，因此本次修复加载、播放及声音竞争，不宣称增加原录音没有的声学细节。
- 网站先完整下载并校验 MP3，再以原字节 Blob 播放，避免网络分段下载在发音中途停顿；当前段、单词重复和下一题复用预加载。内存缓存限制为 48 段 / 8 MiB，跳过正在使用的段；完整个人 HTML 继续直接播放内嵌原录音，直接打开本地部署目录则使用本地 MP3 路径。
- 加载时显示缓冲提示；不完整/损坏的响应会重试，失败明确提示，用户可使用原朗读按钮重试。切题、暂停练习、退出或换播放内容后，旧异步下载不会自行开始发声。
- 原生播放器在时间零附近暂停/继续，不再误触整组重播。完整句子一遍、目标词两遍的顺序及间隔保留，答对后单次目标词朗读保留。
- 保留语速设置并设置标准、WebKit、Mozilla 音高保持属性；练习内修改语速立即生效，下载过程中修改也不会在播放开始时回退。正常 1× 保留原速音色；原生音量及静音选择在续播中保持。
- 示范朗读期间键盘及答题音效降低到原音效设置的 15%，播放停止后沿用原设置。示范与学习者录音回放互斥；切题、暂停或退出也停止自己的录音回放。
- 离线安装只复用哈希正确的完整旧 MP3，避免每次更新重复下载全部录音；播放时发现缓存损坏或截断会联网重新获取，Range 206 与越界 416 保留。
- 原品牌、图片、分类、学习记录、收藏、个人资料、语速、计划、续学位置、备份和数据存储键保留。原网址及 `downloads/frog-study-offline.zip` 路径不变。

## 交付及测试边界

更新原网站及原完整 ZIP，发布后核对 GitHub Pages 构建和线上 HTML、缓存脚本、音频清单、部署 ZIP 的哈希。MP3 保留原有 24 kHz 等来源属性，不将缓冲优化描述为高清重制。音色和源录音发音保持；包括来源说明中已有的 apple 测试录音差异。

测试采用 Chromium 和手机视口/触屏及旧 API 缺失模拟；未在真实手机、Safari 硬件或用户扬声器上试听，不宣称人工逐条音质认证。正常 1× 原速与慢速设置均可使用，浏览器变速的音色效果取决于其实现。
