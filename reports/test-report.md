# 首屏旧版 MVP 闪现修复测试报告

日期：2026-10-25（北京时间）。基于 0b21bb3 原项目继续修改；缓存版本 `frog-first-paint-v21`。

## 原因与修复

修改前，静态侧栏和页面先按旧深色样式绘制；主程序与内嵌资源加载后，render 才添加新版桌面样式。用修改前 HTML 分段发送，已实际复现深色青蛙侧栏先显示的情况。

本次在 head 的小型 ES5 启动脚本中提前判断布局，body 开始解析时同步样式；初始化期间只显示独立加载页，原页面骨架不参与首屏绘制。当前界面准备完毕后直接展示；启动异常会退出加载状态并显示重试入口，保留数据。

联网导航使用 HTTP 重新校验，避免直接沿用仍在有效期内的旧页面；离线继续使用当前版本缓存。原存储键、题库版本、学习记录、设置、音频映射及 610 个 MP3 不变，不调用 TTS 或新增 API。
