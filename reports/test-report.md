# 分类卡片渐隐背景更新

日期：2026-10-26（北京时间）。基于原项目 `9b2db46`，缓存版本 `frog-category-backgrounds-v35`。

## 修改

按标注为 32 个二级分类生成对应主题的卡通插画，以 4 张透明图集提供。有学生人物时沿用首页男孩、女孩造型；数字、颜色、形状、时间、自然等使用对应物品。背景在卡片右侧较清晰，向左渐隐，上下边缘柔化；文字、进度和入口位于背景上层，图像不拦截点击。原卡片布局和操作保持，空分类仍显示真实空状态。

新图片位于 `assets/categories/`，映射为 `data/category-art.json`；来源提示词及哈希见 `reports/category-art-source-sha256.json`。源 PNG 保留于制作工作区，部署 WebP 使用无损编码：透明度和每一个非透明像素的 RGBA 一致，仅 alpha=0 的不可见 RGB 由编码器规范化。未裁切或重绘源图，图集区域与渐隐由 CSS 显示。原 32 个练习图片资源、首页插画、356 条词汇、DJ 音标和 1028 个 MP3 保持。

离线缓存、完整 ZIP 和个人单文件均携带新背景。完整网页导出采用 Blob 下载，备用源码按需读取并保持全文选中复制；很长的二进制脚本字符串使用 JavaScript 行续接分行，解析后的原数据不变。这样避免新增图片后超长源码行及立即渲染整个源码框导致浏览器失败，学习与保存按钮操作保持。
