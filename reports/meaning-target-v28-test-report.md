# 词义对应与参考答案标色测试报告

日期：2026-10-25（北京时间）。基于 c49adb3 原项目；缓存版本 `frog-meaning-target-v28`。

## 本次修改

- 沿用现有界面主题紫色，在中文例句中标出当前作答词对应的部分；词义与参考答案中的作答词使用同色，不改变原题文字。例如 half 对应“半个”，答案中只标色 half，其余英文保持原色。
- 按原有 136 个词条的具体双语例句核对对应关系，其中 133 句有明确的中文片段，另外 3 句采用上下文说明：any 的当前疑问句不单独翻译；zero 的当前中文用“没有饼干”表达零数量；size 的当前问法整体表达为“有多大”。这些说明仅针对各自当前例句，不将省译推广到所有语境。
- 支持不连续的对应片段：“你今天好吗？”只标“你”和“好吗”；“今天”保留原色。名词 dot 对应句末“点”，不误标前面的动词。词义变化也有具体说明，例如 two 对应“两”、number 对应“号码”、short 对应“短”、light 对应“轻”。
- 参考答案按原题填空索引标色，支持整个短语、缩写、连字符和实际复数词形；保留已给出的词、内部标点与原有末尾符号清理规则。答对后的双语例句同样显示对应部分。
- 对应资料存放于 `data/meaning-catalog.json` 并嵌入页面，网站、离线缓存、个人单文件及完整 ZIP 均包含。打包前核对 JSON 与页面内嵌版本一致。
- 导入与原题双语内容及词义相同的副本可以复用对应标色；修改了例句或词义时，不套用旧对应关系，保留实际原句与词条释义并提示结合完整句子理解。全部显示文本按 HTML 转义，既不推断未经核对的逐字翻译，也不执行例句中的 HTML。
- 原居中答案弹窗、遮罩、单个关闭按钮、任意非发音位置/按键关闭、发音按钮只播放及关闭后输入焦点保留。查看答案不判分，提交正确才记录答对。
- 原词库、学习记录、个人资料、收藏、笔记、设置、续学、所有图片与全部 610 个原 MP3 保留；未调用 TTS、生成新录音或修改原录音。沿用原网站及 `downloads/frog-study-offline.zip` 下载路径。
